## QOI divergence

Probe (host drives the 12 x 9 QOI frame, 324 pixel bytes, and logs every 2000
cycles): the gate-level design accepts 145 of 324 input bytes, emits 206 output
bytes, then stops; `status_idle` reads `X` from there on and never recovers,
`status_error` stays 0. The RTL run of the same test passes. An X on a state or
flag in the QOI path is the likeliest cause; not diagnosed further, per the
issue's scope (record and file, do not fix). Filed as #93.
